# Cellar & Co. web demo

Next.js front end for the support agent: landing page with demo personas, the chat (live tool
steps, feedback), and the admin page (feedback labeling, learned knowledge, evals).

```bash
npm install
NEXT_PUBLIC_API_URL=http://localhost:8000 npm run dev
```

The API and everything else are described in the [main README](../README.md).
